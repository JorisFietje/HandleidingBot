Voorbeeld testset voor een chatbot met technische handleidingen 

1. Basisgebruik van instrumenten 

Hoe zet ik apparaat X aan?  

Hoe start ik een nieuwe meting?  

Hoe reset ik het toestel naar fabrieksinstellingen?  

Hoe wijzig ik de meeteenheid van °C naar °F?  

Hoe sla ik meetdata op?  

Hoe exporteer ik meetresultaten naar USB?  

Hoe verbind ik het apparaat met een laptop?  

Hoe lang duurt het opstarten?  

Hoe controleer ik de batterijstatus?  

Hoe schakel ik automatische uitschakeling uit?  

 

2. Installatie en aansluiting 

Welke voedingsspanning heeft model X nodig?  

Welke kabel hoort bij dit instrument?  

Kan dit apparaat via USB-C worden aangesloten?  

Hoe sluit ik de sensor correct aan?  

Welke poort moet ik gebruiken voor kalibratie?  

Mag ik een verlengkabel gebruiken?  

Hoe installeer ik de software voor dit instrument?  

Welke drivers zijn nodig?  

Kan dit toestel draadloos communiceren?  

Welke adapters zijn compatibel?  

 

3. Kalibratie en onderhoud 

Hoe vaak moet dit instrument gekalibreerd worden?  

Hoe voer ik een nulmeting uit?  

Welke kalibratievloeistof moet ik gebruiken?  

Hoe reinig ik de sensor?  

Mag ik alcohol gebruiken om het apparaat schoon te maken?  

Hoe vervang ik de batterij?  

Hoe vervang ik een zekering?  

Hoe controleer ik of het apparaat correct gekalibreerd is?  

Wat is de aanbevolen onderhoudsinterval?  

Welke onderdelen zijn slijtagegevoelig?  

 

4. Foutcodes en storingen 

Wat betekent foutcode E01?  

Wat betekent melding “Sensor Failure”?  

Het apparaat start niet op, wat kan ik doen?  

Waarom krijg ik geen meetwaarde?  

Waarom fluctueert de meting sterk?  

Waarom kan ik geen verbinding maken met de software?  

Wat moet ik doen als het scherm zwart blijft?  

Waarom geeft het apparaat een overload-melding?  

Wat betekent “Calibration Required”?  

Hoe herstel ik een communicatiefout?  

 

5. Technische specificaties 

Wat is het meetbereik van model X?  

Wat is de nauwkeurigheid van dit instrument?  

Wat is de maximale temperatuur waarbij het toestel gebruikt mag worden?  

Is het apparaat waterdicht?  

Welke IP-classificatie heeft het instrument?  

Wat is de responstijd van de sensor?  

Hoeveel interne opslag heeft het toestel?  

Welke protocollen ondersteunt dit apparaat?  

Wat is de maximale drukbelasting?  

Hoe lang gaat de batterij mee?  

 

6. Veiligheid en compliance 

Mag dit instrument buiten gebruikt worden in de regen?  

Kan het apparaat gebruikt worden in ATEX-zones?  

Welke persoonlijke beschermingsmiddelen zijn vereist?  

Mag de behuizing geopend worden door de gebruiker?  

Wat moet ik doen bij oververhitting?  

Is het apparaat geschikt voor explosiegevaarlijke omgevingen?  

Welke veiligheidswaarschuwingen gelden voor de sensor?  

Mag het toestel gebruikt worden bij hoge luchtvochtigheid?  

Hoe vervoer ik het instrument veilig?  

Wat moet ik doen bij beschadiging van de kabel?  

 

7. Vergelijkingsvragen 

Wat is het verschil tussen model X en X Pro?  

Welk toestel is geschikt voor hoge temperaturen?  

Welke sensor heeft de hoogste nauwkeurigheid?  

Welk instrument ondersteunt datalogging?  

Wat is het verschil tussen sensor A en B?  

Welk model is geschikt voor buitengebruik?  

Welke versie ondersteunt Bluetooth?  

Welk instrument heeft de langste batterijduur?  

Welke modellen ondersteunen 4–20 mA?  

Welk apparaat is geschikt voor continue monitoring?  

 

8. Praktische klantscenario’s 

Mijn meting lijkt onrealistisch hoog, wat controleer ik eerst?  

De klant ziet geen data op het display.  

Het toestel valt na enkele minuten uit.  

De sensor reageert erg traag.  

De klant wil meten bij -20°C, kan dat?  

Het apparaat is nat geworden, wat nu?  

De klant heeft de verkeerde voeding gebruikt.  

Het toestel maakt een piepend geluid.  

De meting stopt spontaan.  

De klant weet het exacte model niet.

Ik krijg een foutmelding.  

Welke kabel heb ik nodig?  

Hoe moet ik kalibreren?  

Waarom doet de sensor vreemd?  

Welke instellingen zijn correct?

Waarom krijg ik rare waarden?  

Wat betekent deze melding?  

Hoe moet ik dit aansluiten?
